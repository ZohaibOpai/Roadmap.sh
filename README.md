# 🌐 Responsive Website Project

This is a responsive website created using **HTML and CSS**.  
The project includes a modern layout with navbar, hero section, cards, guides section, timeline, stats, and footer.  
Media queries are used to make the website responsive on **mobile, tablet, and laptop screens**.

---

## 🚀 Technologies Used

- HTML5  
- CSS3  
- Flexbox & Grid  
- Media Queries
